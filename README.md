# Closed-Loop-Smart-Insole-for-Diabetic-Foot-Ulcer-Prevention
Closed-loop smart insole concept for diabetic foot ulcer prevention: senses plantar pressure and temperature, plans pneumatic offloading for 1–3 hotspots, verifies the result, and learns. Simulator, controller, CAD, ESP32-S3 board design. Simulation only, not a medical device.
